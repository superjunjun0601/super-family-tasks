# 超人家族任务清单技术方案

## 1. 推荐技术栈

第一版推荐使用：

- 前端：Next.js + React + TypeScript
- 样式：Tailwind CSS
- 后端：Next.js API routes
- 当前存储：本地 JSON 文件 + 自动备份快照
- 后续数据库：Prisma + PostgreSQL
- 实时更新：SSE 优先，后续可升级 WebSocket
- 定时任务：Node worker / cron
- 部署：VPS + Nginx + HTTPS，或支持数据库的 PaaS
- PWA：manifest + service worker + 基础缓存

## 2. 架构原则

- 第一版优先跑通家庭真实使用闭环。
- 后端负责权限、重复任务、提醒、奖励确认和状态流转。
- 前端保持手机优先，所有关键操作必须适合拇指点击。
- 实时更新先选择实现成本低的 SSE，家庭小规模足够使用。
- PWA 只做基础安装体验，不把离线能力做重。

## 3. 模块拆分

### 登录与权限

- 简单账号密码登录。
- 登录成功后写入 HttpOnly cookie。
- 后端根据用户角色控制权限。
- 预置家庭成员：妈妈、爸爸、小柚子。

### 任务模块

- 支持新增、编辑、删除、恢复、完成、取消完成。
- 支持家庭待办、个人待办、小柚子学习。
- 支持多人负责人。
- 支持备注完整展示。

### 重复任务

- 当前支持每周指定日重复。
- 支持结束日期，不填则一直重复。
- 普通任务完成后自动生成下一次。
- 小柚子任务在爸爸或妈妈确认完成后自动生成下一次。
- 取消完成时撤回系统刚生成、未被继续操作的下一次任务。
- 编辑重复任务时支持“仅本次 / 本次和后续”。同步后续时保留每一次任务自己的日期。

### 提醒模块

- 后端定时扫描任务。
- 根据最晚完成日期，提前 1 / 2 / 3 天开始每天提醒。
- 逾期任务持续提醒。
- 小柚子待确认任务进入提醒流。
- 当前提醒设置已按身份保存，首页提醒铃和提醒页会跟随开关变化。

### 小柚子确认与奖励

- 小柚子完成任务后进入待确认。
- 爸爸或妈妈确认后任务正式完成；设置了奖励时小红花到账。
- 小红花可喂养梦幻小精灵。

### 实时更新

需要推送的事件：

- 任务新增
- 任务编辑
- 任务完成 / 取消完成
- 任务删除 / 恢复
- 评论新增
- 奖励确认
- 提醒变化

## 4. 页面实现顺序

1. 登录页
2. 首页
3. 清单页
4. 任务详情页
5. 新建/编辑任务
6. 提醒页
7. 小柚子页
8. 我的页
9. 设置页
10. 回收站

## 5. 部署建议

### 简单部署

- 一台 VPS。
- PostgreSQL 安装在同机或托管数据库。
- Next.js 服务运行在 Node 进程。
- Nginx 做反向代理。
- Let's Encrypt 配置 HTTPS。

### 后续可扩展

- 数据库迁移到云数据库。
- 提醒 worker 独立进程。
- SSE 升级到 WebSocket。
- 增加微信提醒或第三方通知。

## 6. 第一版取舍

第一版已优先落地：

- 后台同步
- 账号登录
- 任务闭环
- 站内提醒
- 小柚子奖励
- PWA 安装
- 本地 JSON 持久化、自动备份、手动备份、数据自检和安全修复

第一版不做：

- 微信提醒
- 附件上传
- 历史编辑记录
- 复杂统计报表
- 多家庭邀请
