# 家庭试用指南

这份指南用于把当前版本先给家人试用。目标是简单、稳定、知道哪里能找回数据。

## 1. 启动前

先做一次只读检查：

```bash
npm run app:doctor
```

如果想省心一点，可以直接跑试用前一键检查。它会先检查真实数据和代码健康，再用临时数据跑完整冒烟测试，最后再确认临时测试没有污染类型配置：

```bash
npm run app:trial-check
```

也可以跑一次自动冒烟测试。它会使用临时数据目录和独立端口，不会改真实任务；会覆盖登录、修改密码、实时更新、任务校验、评论、权限、提醒设置、小红花、小精灵喂养、重复任务、回收站、手动备份和整包恢复链路：

```bash
npm run app:smoke
```

冒烟测试成功后会清理临时数据和 `.next-smoke` 缓存；如果失败，会保留这些目录方便排查。

正式部署前可以运行更完整的发布检查，它会在试用完整检查之外再做隔离生产构建验证：

```bash
npm run app:release-check
```

如果准备让家人认真试一轮，先备份：

```bash
npm run data:backup
```

正式部署前可以先生成登录密钥，放进 `.env` 或部署平台环境变量：

```bash
npm run auth:secret
```

妈妈也可以在应用里进入 `我的 -> 设置 -> 数据安全` 查看最近手动备份；如果页面提示很久没备份，先点一次 `立即手动备份`。

本地预览启动：

```bash
npm run app:preview
```

电脑本机打开：

```text
http://localhost:3035/
```

手机试用时，让手机和电脑连同一个 Wi-Fi，然后打开 `npm run app:preview` 输出的 `手机同 Wi-Fi` 地址。

如果 3035 上已经开着超人家族任务清单，这个命令会直接提示当前链接，不会再开新端口。
如果链接打不开，先运行 `npm run app:status` 查看当前服务状态和手机同 Wi-Fi 地址；如果状态命令提示当前环境无法访问本机检查地址，但浏览器可以打开打印出的地址，就以浏览器实际访问结果为准。

## 2. 登录身份

初始密码都是：

```text
123456
```

身份：

- 妈妈：管理全部任务、确认小柚子任务、查看数据安全。
- 爸爸：新增任务、编辑自己创建的任务、确认小柚子任务。
- 小柚子：只看自己的任务，完成后等待爸爸妈妈确认。

正式使用前建议三个人都进入 `我的 / 设置 / 修改密码` 改掉默认密码。
`npm run data:check` 也会提醒哪些账号还在使用默认密码，以及最近手动备份是否太久没做。
修改密码后，当前设备会保持登录，其他旧登录会失效，需要用新密码重新进入。

如果同一个身份连续输错密码多次，登录会短暂等待 1 分钟再试，这是为了减少别人乱试密码。乱填不存在的身份也会进入统一限速，避免绕开爸爸、妈妈、小柚子的保护。

## 3. 重点试用流程

妈妈视角：

- 新增一个家庭任务，负责人选爸爸或妈妈。
- 新增一个小柚子任务，设置任务时间、最晚完成时间和小红花。
- 在清单页按分类、负责人、完成状态筛选。
- 手机页面放到后台再回来，确认列表和提醒仍能正常刷新。
- 删除一条任务，再到回收站恢复。
- 进入 `我的 -> 设置 -> 数据安全`，确认能看到健康状态。

爸爸视角：

- 新增一个自己的任务。
- 尝试编辑自己创建的任务。
- 确认小柚子完成后的待确认任务。

小柚子视角：

- 查看小柚子页。
- 勾选一个自己的任务。
- 看任务进入等待确认状态。
- 爸爸或妈妈确认后，再看小红花和精灵等级变化。

## 4. 数据安全

数据默认保存在项目里的 `data/` 目录。正式部署时，如果代码目录会被替换，设置：

```bash
SUPER_FAMILY_DATA_DIR="/var/lib/super-family-tasks"
```

常用命令：

```bash
npm run data:check
npm run data:backup
npm run data:list -- task-store.json
npm run data:restore-latest -- task-store.json
npm run data:restore-manual -- list
```

如果需要把任务、账号和小精灵数据一起恢复到某次手动备份，可运行 `npm run data:restore-manual -- latest`。恢复前会自动再留一份 `before-manual-restore` 备份。

忘记密码时：

```bash
npm run user:reset-password -- mom 新密码
```

`mom` 也可以换成 `dad` 或 `child`。
重置前会自动生成一次手动备份，并额外保留一份 `user-store.json.*.before-password-reset` 文件。

## 5. 已知取舍

- 现在先用站内提醒，不接微信提醒。
- 小精灵能喂养和升级，但更精致的形象和互动留到核心功能稳定后优化。
- 当前默认使用 JSON 文件保存数据，适合家庭小规模使用；以后任务量变大再迁移数据库。
