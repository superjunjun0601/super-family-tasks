# 超人家族任务清单 PRD v1.1

## 1. 产品概述

`超人家族任务清单` 是一款手机优先的家庭任务网页应用，支持 PWA、后台部署、实时更新和多设备同步。

核心覆盖：

- 家庭任务
- 个人待办
- 小柚子学习计划
- 重复任务
- 站内提醒
- 评论
- 小红花奖励
- 梦幻小精灵养成

## 2. 角色权限

### 妈妈

- 超级管理员。
- 可新增、编辑、删除、恢复全部任务。
- 可确认小柚子奖励。

### 爸爸

- 可新增任务。
- 只能编辑、删除自己创建的任务。
- 可勾选完成可见任务。
- 可确认小柚子奖励。

### 小柚子

- 只看自己的任务和学习计划。
- 可勾选自己的任务。
- 奖励需爸爸或妈妈确认后到账。
- 小柚子登录后默认进入小柚子页。
- 小柚子底部导航只保留小柚子和我的，避免进入大人任务流。

### 共通规则

- 所有人可勾选可见任务完成。
- 已完成任务可恢复为未完成。
- 任务可再次编辑。

## 3. 页面结构

- 登录页
- 首页
- 清单页
- 任务详情页
- 提醒页
- 小柚子页
- 我的页
- 回收站

## 4. 首页

展示顺序：

1. 逾期任务
2. 今天任务
3. 明天任务
4. 后天任务
5. 本周任务

规则：

- 首页只展示家庭和大人的个人任务，不混入小柚子学习任务。
- 逾期任务重点提醒。
- 保留快捷新增。
- 已完成任务默认隐藏。
- 按时间流展示。

## 5. 清单页

- 按时间线展示全部任务。
- 清单页只展示家庭和大人的个人任务；小柚子相关任务统一放在小柚子页。
- 已完成任务保留在原时间顺序位置展示。
- 已完成任务使用划线状态，方便看到完成成果。
- 不做复杂 tab。
- 通过筛选缩小范围。

筛选项：

- 任务分类
- 负责人
- 完成状态

## 6. 任务规则

任务分类：

- 家庭待办
- 个人待办
- 小柚子学习

任务字段：

- 标题，必填。
- 备注，可选，填写后必须完整展示。
- 分类，必填。
- 创建人，系统记录但任务卡不展示。
- 负责人，必填，可单人或多人。
- 优先级：紧急 / 重要 / 普通。
- 任务时间，必填。
- 最晚完成时间，必填。
- 提醒规则，可选。
- 是否重复。
- 重复规则。
- 结束日期，不填则一直重复。
- 完成状态。
- 完成人。
- 完成时间。
- 评论列表。
- 小红花奖励。
- 奖励确认状态。
- 删除状态。

完成规则：

- 任意可见成员都可以勾选完成。
- 家庭任务任意成员完成即算完成。
- 已完成可取消完成。
- 小柚子任务进入待确认后，也可以恢复为未完成，避免误点。

编辑规则：

- 妈妈可编辑所有任务。
- 爸爸 / 小柚子只能编辑自己创建的任务。
- 已完成任务也可编辑。
- 重复任务编辑需区分仅本次 / 整个系列。

删除规则：

- 删除前二次确认。
- 删除后进入回收站。
- 支持恢复。
- 妈妈可恢复全部任务；爸爸 / 小柚子只恢复自己创建的任务。

## 7. 任务卡规则

任务卡展示：

- 标题
- 完整备注
- 负责人
- 完成时间
- 优先级
- 重复规则
- 小红花奖励
- 完成 / 待确认状态

提醒规则不放在任务卡片上，进入任务详情页查看。

任务卡不展示：

- 创建人
- 历史编辑记录

小柚子任务待确认时：

- 任务卡醒目标记。
- 文案：`等待确认`。
- 卡片外部直接展示确认按钮，不需要进入详情页才能确认。
- 爸爸或妈妈点击确认后，任务变为已完成；设置了奖励时同时发放小红花。

## 8. 重复与提醒

重复规则：

- 每天
- 每周指定日
- 工作日
- 自定义

提醒规则：

- 任务时间和最晚完成时间分开。
- 根据最晚完成时间，提前 1 / 2 / 3 天开始每天提醒。
- 直到完成为止持续提醒。
- 默认提醒负责人。
- 站内提醒优先。

## 9. 小柚子奖励

- 只有负责人包含小柚子时，任务表单才显示小红花字段。
- 妈妈或爸爸负责的任务不显示小红花，也不记录小红花奖励。
- 小柚子任务可设置小红花数量。
- 奖励数量由创建任务时填写。
- 小柚子完成后进入待确认。
- 待确认状态允许恢复为未完成，避免误点。
- 爸爸或妈妈确认后任务正式完成；设置了奖励时小红花到账。
- 待确认任务需要和普通任务卡片明显区分，并在卡片上直接确认。
- 小红花可喂梦幻小精灵。
- 小精灵包含等级、开心值、喂养状态。

## 10. 回收站

- 展示已删除任务。
- 可点击恢复。
- 支持一键清空。
- 清空前必须二次确认。
- 不显示删除时间。

## 11. 页面交互

### 登录页

- 账号密码。
- 标题：`超人家族任务清单`。
- 简约风格。

### 首页

- 妈妈和爸爸登录后默认进入首页。
- 逾期优先。
- 今天、明天、后天、本周。
- 快捷新增。

### 清单页

- 时间线。
- 搜索。
- 筛选。

### 任务详情页

- 全字段展示。
- 编辑、完成、取消完成、评论、删除、恢复。
- 不展示历史编辑记录。

### 提醒页

- 逾期任务置顶。
- 待确认任务放下面。
- 普通提醒继续排列。

### 小柚子页

- 统一展示小柚子相关任务，不混入首页和清单页。
- 已完成小柚子任务不隐藏，保留原位划线展示，给小柚子成就感。
- 小红花。
- 梦幻小精灵。
- 待确认任务。
- 操作简单。

### 我的页

- 当前账号。
- 我的任务直接列表展示。
- 回收站。
- 设置。
- 退出登录。
- 妈妈管理入口保持轻量。
- 小柚子账号的我的页不显示任务列表、回收站和设置，只显示拥有的小红花、小精灵等级和退出登录。

### 设置页

- 从我的页进入。
- 包含提醒设置。
- 包含修改密码。

## 12. UI 风格
